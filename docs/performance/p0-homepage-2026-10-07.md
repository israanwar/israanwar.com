# ROOT CAUSE

Bootstrap `SunBackground` membuat konteks WebGL sementara saat React merender, lalu renderer membuat konteks lain. Shader solar dan bloom baru disiapkan saat draw pertama. Profil CPU menunjuk `supportsWebGL` (`pr` pada bundle) sebagai salah satu fungsi first-party termahal; trace merekam continuation bootstrap dengan wall time 991,7 ms. `ScrollToTop` juga membaca `documentElement.scrollHeight` saat commit React dan menulis posisi scroll berulang meskipun posisi sudah nol; trace percobaan merekam layout sinkron 94,8 ms.

Ranking diagnostik baseline lokal:

| Sumber | Total CPU diagnostik | Script evaluation |
|---|---:|---:|
| Entry `index-B8J2Gve3.js` | 8.442 ms | 6.491 ms |

| AdSense + SODAR, tiga skrip bernama | 819 ms | 545 ms |

Kategori Unattributable tidak saya atribusikan seluruhnya ke komponen tertentu. Waktu menunggu GPU/native juga berbeda dari waktu CPU; angka di atas merupakan diagnostik Lighthouse, bukan penjumlahan TBT.
