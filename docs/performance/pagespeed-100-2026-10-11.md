# STATUS

IMPLEMENTED — diukur lokal (Lighthouse 12.6.1, build produksi, Brotli, mobile simulated throttling + desktop). Belum diverifikasi di PageSpeed Insights produksi: kuota PSI tanpa API key habis dan situs produksi tidak terjangkau dari sandbox kerja.

# CHANGES

- `LandingPage.jsx`: setiap section di bawah hero dibungkus `<Suspense>` (`DeferredHydration`). React meng-hydrate tiap boundary sebagai pekerjaan terpisah berprioritas rendah, bukan satu long task. HTML hasil prerender tidak berubah.
- `scroll-performance.css`: `content-visibility: auto` + `contain-intrinsic-size: auto` untuk section home di bawah hero (layout/paint awal lebih murah). Tinggi dokumen setelah semua section ter-render identik dengan sebelumnya (7573 px mobile / 6268 px desktop), dan perbandingan piksel per-viewport hanya berbeda pada elemen `fixed`.
- `supabaseData.js` + `publicListProjection.js`: fallback seed untuk `view=folder` dan `view=home` kini memakai proyeksi yang sama dengan `select()` Supabase. Build tanpa data remote tidak lagi menanam 140 layanan dan isi artikel penuh di HTML (`public-bootstrap` home 1,18 MB → 0,07 MB; HTML 1,37 MB → 0,36 MB).
- `public-delivery.mjs`: skrip AdSense dimuat saat interaksi pertama (scroll/tap/tombol) atau fallback 10 detik, bukan di idle awal. Konsekuensi: kunjungan yang tidak berinteraksi selama 10 detik tidak menayangkan iklan.
- `vercel.json`: `Cache-Control: immutable` 1 tahun untuk `/assets/*.{js,css,woff2,wasm}` (nama ber-hash) dan `/assets/fonts/google/*`.
- Aksesibilitas: `aria-label` kartu blog dihapus (nama dari teks terlihat) dan label tombol bahasa kini memuat teks terlihat (audit `label-content-name-mismatch`).
